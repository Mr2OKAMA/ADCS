# SDカード自動識別システム（ADCS.bat）簡易手順書

## 1. 目的
SDカードをPCに挿すだけで、対象データ（`DATA0` / `71VR` / `S000000`）を自動判定して所定フォルダへ転送します。  
- SharePoint（OneDrive同期先）へ **移動（MOVE）**
- Iドライブ（条件一致時）へ **コピー（COPY）**

---

## 2. 事前準備（初回のみ）

### 2-1. OneDriveにサインイン
業務アカウントで OneDrive にサインインし、以下の同期先がPC上で参照できることを確認してください。  
- `SAM_中部チーム - ドキュメント`

### 2-2. ファイル配置
`ADCS.bat` を任意のフォルダに保存してください（例：デスクトップ）。

### 2-3. 実行ポリシー/権限
通常は管理者権限不要です。  
セキュリティ警告が出た場合は、社内ルールに従って許可してください。

---

## 3. 使い方

1. `ADCS.bat` をダブルクリックして起動  
2. 画面に「状態：実行中」と表示されたら待機状態です  
3. SDカードを挿入  
4. 処理完了後、ビープ音が鳴ります  
5. SDカードを抜くと次の待機に戻ります  
6. 終了するときは `Ctrl + C`

---

## 4. 転送ルール（概要）

- 判定ファイル（例：`id_01.txt` ～ `id_31.txt`）に応じて設備名を決定
- 対象拡張子を転送（システム別）  
  - 横河: `.GDS` + `.DAD`  
  - Mシステム: `.71VR` + `.DAD`  
  - フジ: `.FDT` + `.DAD`
- コピー元は自動判定  
  - `DATA0` または `71VR` または `S000000`

---

## 5. ログ確認方法

実行フォルダ配下にログを出力します。  
- `logs\ADCS_YYYYMMDD.log`

エラー時はまずこのログを確認してください。

---

## 6. よくあるトラブル

### 症状1: 起動してすぐエラー終了する
- OneDrive未サインインの可能性があります。  
- OneDriveを起動し、業務アカウントでサインイン後に再実行してください。

### 症状2: SharePointに保存されない
- 同期フォルダがまだ作成されていない/同期中の可能性があります。  
- エクスプローラーで `SAM_中部チーム - ドキュメント` が見えるか確認してください。  
- ログの `[ERROR] SharePoint保存先の作成失敗` / `SharePoint転送失敗` を確認してください。

### 症状3: Iドライブにコピーされない
- `I:\` が未接続、または `I:\id_00.txt` が無いとコピーされません（仕様）。  
- 必要に応じてネットワークドライブ接続を確認してください。

### 症状4: SDカードを挿しても反応しない
- SDカード直下に判定ファイル（`id_XX.txt`）があるか確認してください。  
- `DATA0` / `71VR` / `S000000` のいずれかが存在するか確認してください。

---

## 7. 運用上の注意

- 本ツール実行中は、同じSDカードを他アプリで開かないでください。  
- 転送中にカードを抜かないでください。  
- 異常時はログを添えて管理者へ連絡してください。

---

## 8. 問い合わせ時に伝える情報

問い合わせ時は以下を共有してください。  
1. 実行日時  
2. 使用PC名 / Windowsアカウント  
3. SDカードドライブ文字（例: `E:`）  
4. `logs\ADCS_YYYYMMDD.log` の該当箇所
